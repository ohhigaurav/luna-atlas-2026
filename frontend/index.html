A 5 m grid is not the same as 5 m terrain detail.

LIMITS

What this tool cannot promise

These boundaries are part of the result, not fine print.

↗Earth visible is not a radio link

Link budget, antenna pointing, relay support and network scheduling are outside this geometric model.

☼Sunlight is not power output

Panel angle, efficiency, thermal conditions, storage capacity and energy demand are not modelled here.

±Solver precision is not physical certainty

Root-finding tolerance is not the same as uncertainty in topography, interpolation, datum or ephemeris.

!A feasible window is not a safe landing

This tool does not certify slope, hazards, navigation performance or flight safety.
